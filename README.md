# Система мониторинга сервиса заказов

Комплексный мониторинг микросервисной архитектуры обработки пользовательских заказов на базе **Prometheus** и **VictoriaMetrics**.

---

## О проекте

Проект представляет собой полноценную систему мониторинга для сервиса, который принимает и обрабатывает пользовательские заказы. Мониторинг охватывает все уровни системы — от инфраструктуры (хосты, контейнеры) до бизнес-метрик приложения (заказы, время обработки).

### Компоненты системы

| Компонент     | Назначение                                    |
|---------------|-----------------------------------------------|
| **API**       | Приём HTTP-запросов и создание заказов        |
| **Worker**    | Асинхронная обработка заказов из очереди      |
| **Exporter**  | Экспорт состояния заказов из БД               |
| **PostgreSQL**| Хранение данных о заказах                     |
| **RabbitMQ**  | Брокер сообщений между API и Worker           |

---

## Метрики приложения

### HTTP-метрики (`Api/app/core/metrics.py`)

| Метрика                          | Тип       | Когда снимается               | Описание                          |
|----------------------------------|-----------|-------------------------------|-----------------------------------|
| `http_requests_total`            | Counter   | После каждого HTTP-запроса    | Общее количество запросов         |
| `http_request_duration_seconds`  | Histogram | После каждого HTTP-запроса    | Распределение времени ответа      |
| `shop_orders_created_total`      | Counter   | После успешного `POST /orders`| Общее количество созданных заказов|

### Метрики обработки (`Worker/app/metrics.py`)

| Метрика                                    | Тип       | Когда снимается                          | Описание                                                              |
|--------------------------------------------|-----------|------------------------------------------|-----------------------------------------------------------------------|
| `shop_order_processing_duration_seconds`   | Histogram | После завершения обработки заказа        | Время от получения сообщения из брокера до перевода заказа в `done` (сек) |

### Метрики состояния заказов (`Exporter/app/metrics.py`)

| Метрика               | Тип    | Когда снимается                     | Описание                                    |
|-----------------------|--------|-------------------------------------|---------------------------------------------|
| `orders_new`          | Gauge  | При опросе exporter (~раз в 15 с)   | Количество заказов в статусе `NEW`          |
| `orders_processing`   | Gauge  | При опросе exporter (~раз в 15 с)   | Количество заказов в статусе `PROCESSING`   |
| `orders_done`         | Gauge  | При опросе exporter (~раз в 15 с)   | Количество заказов в статусе `DONE`         |
| `last_processed_at`   | Gauge  | При опросе exporter (~раз в 15 с)   | Время последнего завершённого заказа        |

## Инфраструктурные метрики

### Хост — `node_exporter`

| Метрика                             | Описание                     |
|-------------------------------------|------------------------------|
| `node_cpu_seconds_total`            | Использование CPU            |
| `node_memory_MemAvailable_bytes`    | Доступная оперативная память |
| `node_filesystem_avail_bytes`       | Свободное место на дисках    |

### Контейнеры — `cAdvisor`

| Метрика                                   | Описание                          |
|-------------------------------------------|-----------------------------------|
| `container_cpu_usage_seconds_total`       | Использование CPU контейнерами    |
| `container_memory_working_set_bytes`      | Потребление памяти контейнерами   |
| Сетевой ввод/вывод                        | Сетевая активность контейнеров    |

### PostgreSQL — `postgres_exporter`

| Метрика                          | Описание                        |
|----------------------------------|---------------------------------|
| `pg_up`                          | Доступность СУБД                |
| `pg_stat_database_numbackends`   | Количество активных подключений |
| Метрики активности/транзакций    | Нагрузка на базу данных         |

### RabbitMQ — `rabbitmq_prometheus`

| Метрика                             | Описание                          |
|-------------------------------------|-----------------------------------|
| `rabbitmq_queue_messages_ready`     | Готовые к обработке сообщения     |
| `rabbitmq_queue_messages_unacked`   | Сообщения без подтверждения       |
| `rabbitmq_queue_consumers`          | Количество активных консьюмеров   |
| `rabbitmq_connections`              | Активные подключения к брокеру    |
